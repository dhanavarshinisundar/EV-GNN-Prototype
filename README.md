# EV GNN Prototype
1. Install Python 3.10+.
2. Open this folder in a terminal.
3. Run `pip install -r requirements.txt`
4. Run `streamlit run app.py`
5. Select a driver and change charging type/provider/time to see the Top-N recommendations change.

This is an educational, lightweight GNN-style prototype using synthetic data and transparent neighborhood aggregation. It is designed for a live PG presentation.
